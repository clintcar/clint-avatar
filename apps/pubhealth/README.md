# PubHealth - LiveAvatar NextJS Application

Public health simulation built on the LiveAvatar Web SDK.

This app is a clone of the demo project and will be customized for public health use cases.

## Getting Started

From the repository root:

```bash
pnpm install
pnpm run pubhealth
```

Or navigate to the `apps/pubhealth` directory and run:

```bash
pnpm install
pnpm run dev
```

Navigate to [http://localhost:3010](http://localhost:3010).

## Environment

Copy API secrets configuration from another app (e.g. `apps/demo/app/api/secrets.ts`) or set the required environment variables for your LiveAvatar context.
